# web-scraper-service 0.2.1

The scraper service of the Flow Steward **Web Scraper** extension (`flowsteward.web-scraper`).
It runs in its own container and carries out a whole crawl by itself: discovery, fetching
over HTTP or in a browser, proxy tiers, challenge handling and declarative extraction
mappings. Each run ends in one JSON Lines result file, with the same records as CSV. The
extension calls it over an authenticated HTTP API (contract v1, `contract/` in this
repository).

## Run it

You build the image on your own machine from this repository; no prebuilt image is
published. Download the two files attached to this release into an empty folder:

```bash
mkdir web-scraper && cd web-scraper
curl -fsSLO https://github.com/Flow-Steward/web-scraper-service/releases/download/v0.2.1/docker-compose.yml
curl -fsSL -o .env https://github.com/Flow-Steward/web-scraper-service/releases/download/v0.2.1/env.example
```

Fill `.env`: `WSS_API_TOKEN` and `WSS_SECRETS_KEY` (`openssl rand -hex 32` for each), and
`FS_DOCKER_NETWORK` if your Flow Steward Compact installation does not use the standard
project name (default `flow-steward_default`). Then:

```bash
docker compose up -d
```

The first start builds the image from the tag `v0.2.1`: about 10–15 minutes and about 6 GB
of disk. The Camoufox browser is downloaded from the Camoufox project's official release
during the build and checked against a pinned digest. The service joins Flow Steward's
Docker network, and Flow Steward reaches it at `http://web-scraper:8080` (the platform
needs `FS_ALLOW_PRIVATE_REMOTE_URLS=1` for this private address). The README describes the
host-port alternative, the checks and the Flow Steward setup.

## What it does

- **Discovery:** robots.txt (honoured by default), sitemaps (index, gzip, text), a link
  crawl from a start page or a category, or a given URL list with keys copied to the
  records. Links that lead nowhere useful (accounts, carts, search, facets, files,
  `nofollow`) are skipped, URL traps are capped, and duplicates are collapsed by canonical
  address.
- **Fetching:** an adaptive crawler that switches a host from HTTP to a real browser when
  it has to. Two browsers are in the image: Chromium and Camoufox (Firefox-based). Proxy
  tiers move to the next tier only when a site blocks. Each session keeps a consistent
  identity.
- **Protection:** challenge pages are detected, then a route of browser, wait, next proxy
  tier, an optional one-time checkbox click and an optional paid solver (Turnstile). The
  click and the solvers are off unless the operator enables them. No vision model is used.
- **Extraction:** JSON-LD and declarative mappings (CSS sources, closed transform list,
  multiple values, variants from page and shop data). An AI agent on the Flow Steward
  side writes and repairs the mappings. The service samples pages, tests mappings, and
  opens a mapping request when a template stops matching.
- **Prices:** prices split across tags are read as one amount. Decimal marks are decided
  by the page (language, locale, currency). A sale gives the current price with
  `regular_price` and `on_sale`. Every record has a `price_status` (`shown`, `range`,
  `on_request`, `missing`). The mapping test checks the mapped price against the page's
  machine-readable price.
- **Run behaviour:**
  - One run per site at a time. A second start of a busy site is skipped by default
    (`409 site_busy`), or queued with `when_site_busy: queue`.
  - Politeness presets `gentle`, `normal` (default) and `fast` set the delay, pages at
    once, requests per minute and the page timeout.
  - A host slows down by itself when it returns errors or answers slowly.
  - Answers that are 200 but unusable (empty, truncated, maintenance pages, far too
    small) are retried and never trigger a needless mapping repair.
  - A per-host circuit breaker stops a run on a site that is down, and a stall watchdog
    stops a run that no longer moves.
- **Results and events:** de-duplicated, sorted records with a SHA-256 descriptor and
  ranged download, as JSON Lines or CSV. A finished run's missed pages can be collected
  again. Signed webhooks (HMAC-SHA256) are delivered with back-off across restarts, with
  claim, stage, complete and resend.
- **Operations:** `GET /health` (versions, both browsers, limits, disk), storage report
  and clean-up routes, automatic retention, job secrets encrypted at rest with a key kept
  outside the data volume.

## Requirements

- Docker with Compose v2, on linux/amd64 or linux/arm64 (Docker Desktop on macOS
  and Windows works too).
- About 3 GB of memory, a 1 GB `/dev/shm` and about 6 GB of disk for the image.
- Flow Steward with the Web Scraper extension.

## Use it responsibly

Scrape only sites you are allowed to scrape. robots.txt is honoured unless the operator
explicitly allows an override, and the service does not log in to sites.
